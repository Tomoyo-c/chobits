--------------------------------------------
- How to use the Frutiger Aero Cursor Pack -
--------------------------------------------

Move the Frutiger Aero​ Cursor Pack’s cursor files to the following location: 
C:\Windows\Cursors

Some reason on Windows 11, if the cursor files aren't stored in that folder, 
the system may revert the cursor settings to default over time.

To change cursor schemes, open:

Control Panel > Mouse > Pointers tab
or
Settings > Bluetooth & devices > Mouse > Additional mouse settings > Pointers tab
